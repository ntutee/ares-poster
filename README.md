### 設計重點

- 構圖：左上是主標，左中的黑色天空放活動資訊（Mission Data），地平線以下保留給火星地景與太空人，左下是聯絡資訊（credits）。
- 色彩只用三種：暖象牙白、火星橘紅、暖灰。
- 閱讀層級以實體海報觀看距離設計：
  - 3～5 公尺：絕地救援、2027 NTUT EE CAMP、營期
  - 1～2 公尺：地點、報名時間、對象、QR Code
  - 近看：英文小標籤、Mars 座標、ARES-1 標註、聯絡資訊

## 修改與重新輸出

1. 用文字編輯器修改 `海報版本/12_定稿-聯絡資訊版.html`，所有文字都在 HTML 裡。尺寸單位 `cqw` 是海報寬度的 1%。
2. 重新輸出：
   - **印刷 PDF**：用 Chrome 或 Edge 開啟 HTML，選「列印 → 另存為 PDF」，邊界選「無」，並勾選「背景圖形」。版面已設定為 400 × 600 mm。
   - **4K PNG**：用 Edge 無頭模式截圖：
     ```
     msedge --headless=new --hide-scrollbars --window-size=1280,1920 --force-device-scale-factor=2 --screenshot=out.png 海報版本/12_定稿-聯絡資訊版.html
     ```
3. 需要網路連線載入 Google Fonts（思源宋體、思源黑體、Montserrat、IBM Plex Mono）。

## 關於底圖

`素材/底圖-AI放大4x.png` 由原圖（630 × 945）以 Real-ESRGAN x4plus 放大到 2520 × 3780，並把原圖的星點疊回天空。細節是 AI 推測補上的，近看岩石紋理看得出來。取得真正的高解析度底圖後，用同檔名覆蓋即可，海報不必修改。
